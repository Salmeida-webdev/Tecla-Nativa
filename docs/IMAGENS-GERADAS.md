# Imagens geradas — Tecla Nativa / Fase 1

As imagens foram geradas para este projeto, sem fotos obtidas em lojas ou bancos de imagens. Os 50 produtos usam a mesma direção de arte: fundo de estúdio azul-grafite, enquadramento central, luz suave ciano à esquerda e violeta à direita, materiais escuros e margens internas para preservar o produto inteiro. As imagens quadradas são exibidas com `object-fit: contain` para evitar cortes. Os cards reservam um único quadro quadrado por imagem, sem altura excedente. Os produtos são renders conceituais genéricos e podem conter detalhes físicos ou técnicos imprecisos. Validar/substituir por imagens correspondentes ao produto real antes de uma operação comercial.

## Hero

- `public/images/hero-home-office-v4.webp` — nova imagem principal com enquadramento próximo, teclado, mouse e headset ocupando o quadro.
- `public/images/setup-workspace.webp` — imagem editorial para o banner de recomendação de espaço. Ambas seguem a iluminação ciano/violeta da loja.
- Os arquivos originais das pranchas geradas foram usados para criar os 50 WebP finais e não são necessários para executar o projeto.
